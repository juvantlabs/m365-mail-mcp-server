# Hardys — UI kit

The Teaching Intelligence OS. This kit covers both:
- **Marketing** (`index.html` default view) — hero + feature surfaces + CTA
- **Product** — in-app screens for The Room, The Mirror, The Lens, The Folio (toggle via the app-switcher pill in the top-right)

## Files
- `index.html` — clickable shell that routes between Marketing / Room / Mirror / Lens / Folio
- `Marketing.jsx` — hero, features, quote, CTA
- `AppShell.jsx` — chrome (sidebar + topbar) shared by product screens
- `Room.jsx`, `Mirror.jsx`, `Lens.jsx`, `Folio.jsx` — product screens
- `hardys-primitives.jsx` — buttons, badges, small shared atoms

## Notes
Built from brand guidelines + asset set. No product source exists yet — this is a visual-fidelity first pass using the Juvant node/arc motif and the violet→cyan palette.
